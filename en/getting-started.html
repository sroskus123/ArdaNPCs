Getting started

Install ArdaNPCs 1.1.0, create your first NPC and learn the essential controls.

What you need

This guide covers ArdaNPCs 1.1.0. Start in a test world where you have administrator permissions. You can create your first character entirely in game; no scripts or JSON editing are needed.

ComponentRequirement
Minecraft Java Edition1.21.8
Mod loaderFabric Loader 0.19.3 or a newer compatible version
Fabric API0.136.1+1.21.8 or a newer compatible release for Minecraft 1.21.8
Java21 or later
ModArdaNPCs-1.1.0.jar
NPC administrationOperator permission level 2 or higher

Use the Fabric build. In multiplayer, install ArdaNPCs and Fabric API on the server and every joining player's client. A server-only installation is not sufficient for the editor, custom screens and NPC rendering.

Install and launch

  1. Close the game. Before changing an existing server, stop it cleanly and back up the entire world.
  2. Prepare a Minecraft 1.21.8 profile with a suitable Fabric Loader.
  3. Download the mod from its official CurseForge page. Place its JAR and the matching Fabric API JAR in that instance's mods folder. When updating, remove the old ArdaNPCs JAR from that folder so two versions of the same mod are not installed together.
  4. Launch the Fabric profile. For multiplayer, prepare the server and clients with matching requirements.
  5. Open a test world with commands enabled, or join as an operator. Check that /ardanpcs list is available. An empty NPC list is normal in a new world.

If the command is missing, check the profile, game version and mod installation. If it exists but you cannot use it, check permissions. Resolve dependency errors during startup before opening your main world; see troubleshooting.

Create your first NPC

  1. Stand in a clear, level area and look ahead. Enter this command in chat:
/ardanpcs create Gate Guard

The NPC appears approximately two blocks along your view direction. The confirmation includes its name and UUID. The UUID is the character's persistent identifier. Names can change, which is why administrative commands use UUIDs.

  1. Get an Arda NPC Wand from the creative inventory, or use the following command.
/give @s arda_npcs:npc_wand
  1. Hold the wand and right-click the NPC itself. This opens that character's editor.
  2. In General, choose a name and an optional title, such as “City Watch”. For this first check, keep Passive mode and Standing movement in AI.
  3. Click Save and check the server confirmation. Closing the screen is not a save confirmation.
  4. Put the wand away and right-click the NPC. A new character without configured dialogs or services uses a simple greeting. This checks normal player interaction.
  5. Open the editor again and follow Dialogs and quests to add a conversation and a task.

You can also create NPCs with the wand: right-click a block. An “Arda NPC” character appears next to the clicked face. Aim directly at an existing NPC when opening its editor; clicking the block beside it can create another character.

Three different interactions

ActionResult
Right-click an NPC with the Arda NPC WandAdministrator editor; requires OP level 2.
Right-click without the wandNormal configured interaction, such as a dialog, role or other enabled behavior.
Hold the sneak key and right-click without the wandOpens the NPC's available services. The default sneak key is Shift.
/ardanpcs managerNPC Manager for finding, selecting and administering characters.

Players do not need operator permissions just to use dialogs and quests. Administrator access is for creating and editing content. Also test your setup as an ordinary player, particularly quest availability, service prices and combat targeting.
